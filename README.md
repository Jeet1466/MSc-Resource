# MSc-Resource

A centralized resource management portal built as a milestone project during a Laravel Certification Course. Designed specifically to host, organize, and distribute academic resources for postgraduate IT students.

## 🚀 Features
* **Academic Repository:** Store, view, and download subject-wise study materials, notes, and previous year questions.
* **No-Code Admin Panel:** Fully featured administrative portal to upload files, manage categories, and handle user permissions without technical overhead.
* **Production Deployed:** Optimized database schema and asset loading, verified via live production deployment.

## 🛠 Tech Stack
* **Backend:** PHP / Laravel
* **Frontend:** Blade Template Engine, Tailwind CSS / Bootstrap
* **Database:** MySQL
